# 幻尔 miniAuto 智能小车 · 产品概览与教学方案

> 幻尔 miniAuto 系列是面向 AI 教育的开源编程智能小车，以 Arduino UNO 为核心控制器，配备 AI 视觉模块与全向麦克纳姆轮，支持从图形化编程到 Python/AI 大模型的完整学习路径。本教程基于 **AI 视觉豪华版** 与 **AI 大模型旗舰版** 两个版本展开教学。

---

## 一、产品简介

### 1.1 什么是 miniAuto

miniAuto 是幻尔科技（Hiwonder）推出的入门级 AI 视觉智能小车，完全兼容 Arduino 开源生态。它采用紧凑的 100mm×100mm 底盘设计，搭载全向麦克纳姆轮，可实现 360° 自由移动、定圆漂移等灵活运动。

**核心特点：**
- **AI 视觉识别**：ESP32-S3 视觉模块，支持颜色识别/追踪、巡线、人脸识别
- **全向移动**：麦克纳姆轮底盘，支持前进、后退、横移、斜行、漂移
- **Arduino 兼容**：UNO R3 控制器 + 扩展板，支持 Arduino IDE 编程
- **APP 控制**：蓝牙连接 Wonderbot APP，实时监控与遥控
- **开源生态**：完整源码、库文件与教程开放

### 1.2 两个版本对比

| 对比项 | AI 视觉豪华版 | AI 大模型旗舰版 |
|--------|-------------|---------------|
| 主控 | Arduino UNO (ATmega328) | ESP32 + AI 大模型模块 |
| 视觉模块 | ESP32-S3 摄像头 | ESP32-S3 + 大模型视觉 |
| 语音交互 | 无 | AI 大模型语音对话 |
| 机械臂 | 可选配（2DOF） | 标配 2DOF 机械臂 |
| 编程方式 | Arduino C/C++ | Scratch 图形化 + Python |
| ROS 支持 | 无 | 支持 ROS 通信 |
| AI 能力 | 视觉识别/追踪 | 视觉 + 语音 + 大模型推理 |
| 适合学段 | 中小学 ~ 高中 | 高中 ~ 大学 |
| 续航 | ~60 分钟（18650 锂电池） | ~60 分钟 |

### 1.3 教学定位

- **AI 视觉豪华版**：侧重 **感知技术入门**，适合学习计算机视觉基础、Arduino 编程、传感器融合，完成颜色追踪、自动巡线、避障等经典项目
- **AI 大模型旗舰版**：侧重 **AI 全栈体验**，在学习视觉基础上增加大模型语音交互、Scratch/Python 双模编程，适合进阶学习 AI 应用开发

## 三、教学路线规划

### 3.1 中小学阶段（K12）

**使用版本**：AI 视觉豪华版

**学习目标**：
1. 认识智能小车的基本结构与传感器
2. 学会 Arduino IDE 环境搭建与基础编程
3. 完成运动控制基础（前进、后退、转弯、漂移）
4. 体验 AI 视觉功能（颜色识别、颜色追踪）
5. 完成避障小车与巡线小车项目

**课时建议**：8-12 课时，每课时 45 分钟

### 3.2 高中阶段

**使用版本**：AI 视觉豪华版 + AI 大模型旗舰版

**学习目标**：
1. 深入理解计算机视觉原理（HSV 色彩空间、图像处理）
2. 掌握传感器融合技术（视觉 + 超声波 + 巡线）
3. 学习 AI 大模型的基本概念与语音交互原理
4. 完成智能运输、人脸识别追踪等综合项目
5. 了解 ROS 机器人操作系统基础

**课时建议**：12-16 课时

### 3.3 大学阶段

**使用版本**：AI 大模型旗舰版

**学习目标**：
1. 基于 Python 的 AI 视觉应用开发
2. 大模型 API 调用与语音交互集成
3. ROS 通信与多节点协同
4. 自动驾驶算法仿真（SLAM、路径规划）
5. 综合项目：智能物流机器人 / AI 助手小车

**课时建议**：16-24 课时
