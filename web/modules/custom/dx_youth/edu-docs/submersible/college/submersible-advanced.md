# 水下潜航器 · 大学进阶教程

> 面向大学及以上水平，深入讲解 AUV 自主导航、水下 SLAM、多 AUV 协同、深海作业级 ROV 控制等前沿技术。

---

## 一、AUV 自主导航

### 1.1 水下导航挑战

| 挑战 | 原因 | 解决方案 |
|------|------|---------|
| 无 GPS | 电磁波在水中衰减极快 | INS/DVL/USBL/地形匹配 |
| 通信受限 | 声波带宽低、延迟高 | 事件触发通信、自主决策 |
| 感知困难 | 水下能见度低、光照差 | 声呐成像、前视声呐 SLAM |
| 能源有限 | 电池容量受限 | 路径规划优化、水下滑翔机 |

### 1.2 惯性导航 + DVL 组合

**INS（惯性导航系统）**：
- 加速度计 + 陀螺仪 → 积分得到位置和姿态
- 缺点：累积误差随时间增长

**DVL（多普勒速度仪）**：
- 向海底发射声波，测量多普勒频移 → 得到对地速度
- 精度：0.1% 速度值
- 与 INS 组合可大幅抑制漂移

**卡尔曼滤波融合**：
```
状态向量 x = [位置, 速度, 姿态, 陀螺零偏, 加速度零偏]
预测步：x_pred = F × x + B × u
更新步：x = x_pred + K × (z - H × x_pred)
```

### 1.3 USBL 水下声学定位

**USBL（Ultra-Short Baseline）**：
- 水面母船安装 USBL 基阵
- AUV 携带应答器
- 测量声波到达时间差 → 计算 AUV 相对母船的位置
- 精度：0.1% × 斜距（如 1000m 距离，精度 1m）

## 二、水下 SLAM

### 2.1 声呐 SLAM

水下视觉 SLAM 困难（低能见度），主流用声呐 SLAM：

**前视声呐成像特点**：
- 极坐标成像（非笛卡尔坐标）
- 方位角分辨率高，距离分辨率低
- 存在多径效应和声学阴影

**声呐 SLAM 算法**：
1. **特征提取**：从声呐图像提取点/线/面特征
2. **数据关联**：匹配相邻帧的特征
3. **位姿估计**：ICP/NDT 配准
4. **回环检测**：识别曾到过的地方
5. **后端优化**：图优化/因子图

### 2.2 地形匹配导航

利用海底地形作为"指纹"进行定位：
1. 搭载深度传感器扫描海底地形
2. 与预存的海底地形图匹配
3. 确定 AUV 的绝对位置

**适用场景**：深海平原区域（地形特征少）效果差；海底山脉/峡谷区域效果好。

## 三、多 AUV 协同

### 3.1 协同搜索

多台 AUV 协同搜索目标（如黑匣子、沉船）：

**编队模式**：
- **平行割据**：各 AUV 平行前进，覆盖搜索带
- **螺旋扩展**：从中心向外螺旋搜索
- **自适应**：根据已探测信息动态调整路线

**通信约束**：
- 水下通信带宽极低（kbps 级）
- 传播延迟大（声速 1500m/s，1km 延迟 0.67s）
- 策略：只在关键时刻通信，其余时间自主决策

### 3.2 协同搬运

多台水下机器人协同搬运大型物体：
- 需要精确的力/位混合控制
- 各 AUV 必须同步运动
- 通过水声通信实时同步状态

## 四、深海作业级 ROV

### 4.1 作业级 ROV 特点

| 参数 | 观察级 | 作业级 |
|------|--------|--------|
| 深度 | <1000m | <6000m |
| 推力 | <200N | >2000N |
| 机械臂 | 无/小型 | 7 自由度力反馈 |
| 载荷 | 摄像头 | 液压工具、切割器 |
| 功率 | <5kW | >100kW |

### 4.2 力反馈机械臂控制

深海作业级 ROV 的机械臂需要：
- **力感知**：关节力矩传感器
- **力控制**：恒力抓取（不损坏脆弱目标）
- **主从控制**：操作员在地面操控，ROV 机械臂同步动作
- **延迟补偿**：水声通信延迟 → 预测控制

### 4.3 水下焊接与切割

特殊作业需要：
- **水下焊接**：湿法焊接（直接在水中）或干法焊接（局部排水舱内）
- **水下切割**：氧弧切割、激光切割（实验阶段）
- 应用：海底管道维修、沉船打捞、海上风电维护

## 五、脑电波 + 水下机器人前沿

### 5.1 BCI 控制 ROV 研究

已有研究表明脑电信号可用于水下机器人控制：
- **P300 事件相关电位**：注视不同目标产生不同脑电 → 选择指令
- **运动想象**：想象左手/右手运动 → 控制不同动作
- **SSVEP**：注视不同频率闪烁 → 选择指令

### 5.2 实现架构

```
脑电头环 (BCI)
    ↓ 蓝牙
上位机 (Python)
    ↓ 脑电解码 → 意图识别
    ↓ 映射为 ROV 控制指令
水声通信机 / 有缆
    ↓
ROV 控制板
    ↓
推进器/机械臂执行
```

### 5.3 技术挑战

- **脑电信号噪声大**：水下环境振动、电磁干扰
- **通信延迟**：水声通信延迟可能导致控制不稳定
- **安全性**：脑电解码错误可能导致 ROV 碰撞 → 需要安全边界
