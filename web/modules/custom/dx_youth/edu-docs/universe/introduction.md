# 宇宙理论与实践 — 板块引言

> 当超级智能（SI）时代来临，人类智力或将成为寻常之物。但有一项探索永无止境——那就是宇宙。

## 为什么是宇宙？

人工智能正在以前所未有的速度发展。美国已将最前沿的 AI 定义为 **Super Intelligence（SI）**。也许未来十到二十年，在 SI 之下，人类的智力将成为普通的产物——智力平权与平等将变得普遍。

但是，有一项事业是人类仍在不断探索和攻克的，那就是**宇宙**。

宇宙的尺度超越想象：可观测宇宙直径约 930 亿光年，包含至少 2 万亿个星系。我们仍不知道暗物质是什么、暗能量从何而来、宇宙的最终命运如何。这些根本性的问题，需要一代又一代人持续探索。

## 板块定位

**宇宙理论与实践**板块面向青少年（也适用于探索型成年人），提供从启蒙到前沿的完整学习路径：

| 阶段 | 内容 | 适合人群 |
|------|------|----------|
| **中小学 · 启蒙与探索** | 星空认知、太阳系、NASA 活动手册、Stellarium 天文馆 | 小学至初中 |
| **高中 · 原理与观测** | 天文学基础、引力与暗物质、恒星演化、Coursera 课程 | 高中 |
| **大学 · 深度与前沿** | 广义相对论、宇宙学、JWST 数据、CosmicAI、CAMELS 模拟 | 大学及以上 |
| **仿真工具** | Stellarium、Celestia、WorldWide Telescope | 全年龄段 |
| **竞赛** | CNAO 全国中学生天文知识竞赛、IOAA 国际天文奥赛 | 中学生 |

## 核心理念

1. **理论与实践并重**：不只学知识，更要动手观测、分析数据、运行模拟
2. **开源优先**：优先使用开源工具和公开数据，让任何人都能参与宇宙探索
3. **从启蒙到前沿**：覆盖从 4 岁儿童到专业研究者的完整学习路径
4. **AI + 宇宙**：利用 AI/SI 工具加速宇宙学研究和数据分析

## 宇宙探索的根本问题

- 宇宙从何而来？将往何处去？
- 暗物质和暗能量的本质是什么？（占宇宙总质能的 95%）
- 地球之外是否存在生命？
- 时空的本质是什么？（广义相对论与量子引力的统一）
- 宇宙是否有边界？是否有平行宇宙？

这些问题不仅是科学的，也是哲学的。它们激发人类最深层的好奇心，推动我们不断向前。

## 学习建议

**中小学生**：从 Stellarium 开始，认识星座和行星，参加 CNAO 竞赛
**高中生**：学习 Coursera 天文课程，理解引力和宇宙演化
**大学生**：深入广义相对论和宇宙学，使用 JWST/NASA 公开数据进行研究
**探索型成年人**：用 Celestia 漫游宇宙，用 WorldWide Telescope 观测深空
