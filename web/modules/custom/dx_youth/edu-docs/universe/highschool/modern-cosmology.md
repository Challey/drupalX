## 第一章：宇宙的年龄与尺度

### 1.1 哈勃定律

```
哈勃定律：v = H₀ × d

其中：
├── v: 星系退行速度（km/s）
├── d: 星系距离（Mpc，百万秒差距）
├── H₀: 哈勃常数 ≈ 67.4 ~ 73.0 km/s/Mpc
└── 1 Mpc ≈ 3.26 × 10⁶ 光年

含义：
├── 宇宙在膨胀
├── 越远的星系退行越快
└── 宇宙有一个起点（大爆炸）
```

### 1.2 宇宙距离阶梯

```
测量宇宙距离的方法（由近到远）：

第 1 级：太阳系内（< 1000 AU）
├── 雷达测距：向行星发射无线电波，测量回波时间
├── 精度：±1 km
└── 最远：金星约 1.3 AU

第 2 级：邻近恒星（< 1000 光年）
├── 视差法：地球绕太阳运动时，恒星位置的微小变化
├── d = 1/p（p 为视差角，角秒）
├── Gaia 卫星精度：±10 微角秒
└── 最远：约 10,000 光年

第 3 级：银河系内（< 10 万光年）
├── 标准烛光：造父变星（周期-光度关系）
├── 天琴座 RR 变星
├── 主序星拟合
└── 精度：±10%

第 4 级：邻近星系（< 1 亿光年）
├── Ia 型超新星（标准烛光，峰值光度一致）
├── 塔利-费舍尔关系（旋涡星系）
├── 表面亮度起伏
└── 精度：±5%

第 5 级：遥远星系（> 10 亿光年）
├── Ia 型超新星（高红移）
├── 重子声学振荡（BAO）
├── 引力透镜时间延迟
└── 精度：±10%
```

### 1.3 红移与宇宙膨胀

```
红移（Redshift）：

定义：z = (λ_obs - λ_emit) / λ_emit

物理意义：
├── z < 0.1: 多普勒红移（星系本动速度）
├── 0.1 < z < 10: 宇宙学红移（空间膨胀拉伸光波）
└── z > 10: 极高红移（早期宇宙）

关键红移值：
├── z ≈ 0: 现在
├── z ≈ 1: 宇宙年龄约 60 亿年
├── z ≈ 10: 宇宙年龄约 5 亿年（再电离时期）
├── z ≈ 1100: 宇宙微波背景辐射（复合时期）
├── z ≈ 10⁹: 大爆炸核合成
└── z → ∞: 大爆炸奇点
```

## 第二章：宇宙微波背景辐射（CMB）

### 2.1 CMB 的发现与意义

```
CMB 关键参数：
├── 温度：T = 2.725 K（-270.4°C）
├── 发现：1965 年 Penzias & Wilson（诺贝尔奖）
├── 精确测量：COBE → WMAP → Planck 卫星
├── 黑体谱：完美符合普朗克公式
├── 各向异性：ΔT/T ≈ 10⁻⁵（十万分之一）
└── 极化：E 模式已测，B 模式待测
```

### 2.2 CMB 功率谱

```python
import numpy as np
import matplotlib.pyplot as plt

def cmb_power_spectrum(ell):
    """
    CMB 温度功率谱近似计算
    
    参数：
        ell: 多极矩（2 ~ 2500）
    
    返回：
        C_ell: 功率谱值
    """
    # 声学峰位置（近似）
    peaks = [220, 540, 810, 1100, 1400]
    peak_heights = [8000, 3500, 2500, 1800, 1200]
    peak_widths = [80, 100, 100, 100, 100]
    
    # 阻尼尾（Silk damping）
    damping = np.exp(-ell / 3000)
    
    # 萨克斯-沃尔夫效应（大尺度）
    sw_plateau = 1000 * (ell / 100)**(-0.9)
    
    # 声学峰叠加
    spectrum = sw_plateau * damping
    for mu, A, sigma in zip(peaks, peak_heights, peak_widths):
        spectrum += A * np.exp(-(ell - mu)**2 / (2 * sigma**2))
    
    return spectrum

# 绘制功率谱
ell = np.arange(2, 2500)
C_ell = cmb_power_spectrum(ell)

plt.figure(figsize=(10, 6))
plt.loglog(ell, ell * (ell + 1) * C_ell / (2 * np.pi))
plt.xlabel('Multipole moment ℓ')
plt.ylabel('ℓ(ℓ+1)C_ℓ / 2π (μK²)')
plt.title('CMB Temperature Power Spectrum')
plt.grid(True, alpha=0.3)
plt.show()
```

## 第三章：暗物质与暗能量

### 3.1 暗物质证据

```
暗物质的四条独立证据：

1. 星系旋转曲线
   ├── 观测：星系外围恒星速度不随距离下降
   ├── 预期：v ∝ 1/√r（开普勒定律）
   ├── 实际：v ≈ 常数（平坦旋转曲线）
   └── 结论：存在暗物质晕

2. 星系团动力学
   ├── 维里定理：2K + U = 0
   ├── 观测：星系速度弥散太大
   ├── 可见物质不足以束缚星系团
   └── 结论：暗物质提供额外引力

3. 引力透镜
   ├── 光线经过大质量天体时弯曲
   ├── 观测：背景星系图像扭曲
   ├── 质量重建：远超可见物质
   └── 结论：暗物质分布与可见物质不同

4. CMB 各向异性
   ├── 声学峰位置对物质密度敏感
   ├── 第一峰位置：确定 Ω_m
   ├── 峰值高度比：确定 Ω_b / Ω_m
   └── 结论：暗物质 ≈ 5 × 重子物质
```

```
暗物质粒子候选：
```

### 3.3 暗能量与宇宙加速

```
暗能量状态方程：

p = w × ρ × c²

其中：
├── p: 暗能量压强
├── ρ: 暗能量密度
├── c: 光速
└── w: 状态方程参数

不同模型：
├── 宇宙学常数 Λ：w = -1（恒定密度）

宇宙命运：
├── w = -1: 永远加速膨胀，热寂
├── w > -1: 加速减缓，可能停止
├── w < -1: 大撕裂（Big Rip），所有结构被撕碎
└── 当前最佳拟合：w ≈ -1（热寂）
```

### 4.2 LIGO 探测原理

```python
class LIGODetector:
    """
    LIGO 激光干涉引力波探测器
    
    原理：
    ├── 两臂长 4 km，互相垂直
    ├── 激光在臂中往返，测量光程差
    ├── 引力波经过时，一臂拉伸，一臂压缩
    └── 干涉条纹变化 → 探测引力波
    """
    
    def __init__(self, arm_length=4000, laser_power=200):
        self.arm_length = arm_length  # 米
        self.laser_power = laser_power  # 瓦特
        self.sensitivity = 1e-23  # 应变灵敏度
    
    def compute_strain(self, signal):
        """
        计算引力波应变
        
        h = ΔL / L
        """
        delta_L = signal  # 光程差
        h = delta_L / self.arm_length
        return h
    
    def matched_filter(self, data, template):
        """
        匹配滤波：从噪声中提取引力波信号
        
        原理：将数据与理论波形模板做互相关
        SNR = (data | template) / sqrt((template | template))
        """
        # 傅里叶变换
        data_fft = np.fft.fft(data)
        template_fft = np.fft.fft(template)
        
        # 噪声功率谱密度
        psd = self.noise_psd(len(data))
        
        # 加权互相关
        inner_product = np.sum(np.conj(data_fft) * template_fft / psd)
        norm = np.sqrt(np.sum(np.abs(template_fft)**2 / psd))
        
        snr = inner_product / norm
        return snr
```

## 第五章：系外行星探测

### 5.1 凌星法

```python
def transit_lightcurve(time, period, t0, depth, duration):
    """
    模拟凌星光变曲线
    
    参数：
        time: 观测时间数组
        period: 轨道周期（天）
        t0: 凌星中心时刻
        depth: 凌星深度 (R_p/R_star)²
        duration: 凌星持续时间（天）
    """
    # 轨道相位
    phase = ((time - t0) % period) / period
    
    # 凌星条件
    in_transit = np.abs(phase - 0.5) < duration / (2 * period)
    
    # 光变曲线
    flux = np.ones_like(time)
    flux[in_transit] -= depth
    
    return flux

# 凌星参数与行星性质：
# ├── 凌星深度：ΔF/F = (R_p/R_star)² → 行星半径
# ├── 凌星周期：P → 轨道半长径（开普勒第三定律）
# ├── 凌星持续时间：T → 轨道倾角
# └── 凌星形状：U 型 vs V 型 → 撞击参数
```
