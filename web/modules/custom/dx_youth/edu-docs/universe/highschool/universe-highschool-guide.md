# 宇宙探索 · 高中原理与观测指南

> 面向高中阶段，以天文学基础原理、观测实践和竞赛准备为主。

## 天文学核心知识框架

### 天球坐标系
天文学的基础工具，用于精确定位天体：
- **赤道坐标系**：赤经（RA）+ 赤纬（Dec），类似地球经纬度
- **地平坐标系**：方位角 + 高度角，以观测者为中心
- **黄道坐标系**：以黄道面为基准，用于太阳系天体
- **银河坐标系**：以银河面为基准

### 恒星物理
- **赫罗图（H-R Diagram）**：恒星光度 vs 表面温度，揭示恒星演化路径
- **恒星分类**：O-B-A-F-G-K-M 七大光谱型（"Oh Be A Fine Girl/Guy, Kiss Me"）
- **恒星演化**：星云 → 主序星 → 红巨星 → 白矮星/中子星/黑洞
- **核聚变**：氢 → 氦 → 碳 → 铁，质量决定最终命运

### 太阳系与系外行星
- 八大行星的基本参数（质量、半径、轨道周期）
- 开普勒三定律及其物理含义
- 系外行星探测方法：凌日法、径向速度法、直接成像法
- 宜居带的概念与条件

### 星系与宇宙学基础
- 银河系结构：银心、银盘、银晕、暗物质晕
- 哈勃定律：v = H₀ × d，宇宙膨胀的定量描述
- 大爆炸理论的关键证据：CMB、轻元素丰度、哈勃膨胀
- 暗物质与暗能量的基本概念

## 观测实践

### 实践 1：望远镜基础操作
- **目标**：掌握光学望远镜的基本使用方法
- **内容**：
  - 折射式 vs 反射式望远镜的原理区别
  - 焦距、口径、放大倍率的计算
  - 使用 Stellarium 规划观测目标
  - 实际操作望远镜对准月球/行星

### 实践 2：恒星光谱分析
- **目标**：通过光谱了解恒星的物理性质
- **工具**：简易衍射光栅片 + 望远镜
- **内容**：
  - 观察不同恒星的颜色差异
  - 理解光谱型与温度的关系
  - 分析吸收光谱线的含义

### 实践 3：变星光度测量
- **目标**：通过测光发现变星周期
- **工具**：小型望远镜 + CCD/CMOS 相机
- **内容**：
  - 选择一颗已知变星（如造父变星）
  - 连续多晚测量亮度变化
  - 绘制光变曲线，确定周期
  - 理解周光关系在测距中的应用
