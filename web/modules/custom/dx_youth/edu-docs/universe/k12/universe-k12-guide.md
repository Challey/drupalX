# 宇宙探索 · 中小学启蒙指南

> 面向小学至初中阶段，以星空认知、宇宙启蒙和动手实践为主。

## 宇宙有多大？

可观测宇宙的直径约 **930 亿光年**，包含至少 **2 万亿个星系**。我们的地球只是银河系中一颗普通行星，而银河系只是宇宙中数十亿个星系之一。

## NASA 宇宙探索资源

### NASA Space Place
NASA 官方宇宙探索教育平台，提供：
- **涂色页与手工活动**：太阳系行星涂色、纸模型制作
- **互动游戏**：行星匹配、星系探索
- **视频动画**：黑洞、恒星、星系等概念的趣味讲解
- **学前书写练习**：以宇宙主题的线条练习书写

来源：https://science.nasa.gov/universe/

### NASA 活动手册下载
NASA 提供多本免费教育活动手册 PDF：
- **太阳系探索手册**：了解八大行星、小行星带、柯伊伯带
- **恒星生命周期手册**：从星云到红巨星、白矮星、中子星、黑洞
- **月球观测手册**：月相变化、月球地貌

来源：https://spaceplace.nasa.gov/activity-books/

## Universe in a Box 教育工具包

**国际天文学联合会（IAU）** 旗下的宇宙教育工具包（UNAW），专为 4-10 岁儿童设计：

- **内容**：太阳系模型、恒星生命周期、星系概念
- **形式**：实物模型 + 教师指南 + 活动方案
- **语言**：多语言版本可用
- **获取**：https://www.unawe.org/resources/universebox/

## Stellarium 开源天文馆

**Stellarium** 是最适合青少年使用的开源天象模拟软件：

### 核心功能
- 默认星表超过 **60 万颗恒星**，深空天体超过 **8 万个**
- 支持 **40 多种文化** 的星座划分，包括**中国古代星官体系**
- 逼真的银河、大气效果、行星运动
- 时间控制：可以回到过去或跳到未来任何日期
- 支持裸眼、双筒望远镜、天文望远镜三种视角

### 教学应用
- **认星座**：用 Stellarium 识别四季主要星座和亮星
- **看行星**：模拟木星、土星等行星的实时位置
- **观月相**：展示任意日期的月相变化
- **模拟日食/月食**：重现历史或未来的日月食

### 获取
- 官网：https://stellarium.org/zh_CN/
- 平台：Windows / macOS / Linux
- 许可：GNU GPL v2（完全免费开源）

## 实践课题

### 课题 1：我的星空日记
- **目标**：连续 30 天记录每晚可见的主要星座和亮星
- **工具**：Stellarium + 笔记本
- **步骤**：
  1. 每晚同一时间观察北方天空
  2. 用 Stellarium 确认看到的星座名称
  3. 记录观察时间、天气、可见星座
  4. 30 天后总结星座随季节的变化规律

### 课题 2：太阳系比例模型
- **目标**：理解太阳系各行星之间的距离比例
- **材料**：尺子、纸、标记物
- **步骤**：
  1. 设定比例尺（如 1 厘米 = 1 亿公里）
  2. 计算各行星到太阳的图上距离
  3. 在校园或公园中实际标出行星位置
  4. 体会行星间距离的巨大差异

### 课题 3：月相观测与预测
- **目标**：理解月相变化规律
- **工具**：Stellarium + 实际观察
- **步骤**：
  1. 用 Stellarium 查看本月每天的月相
  2. 每晚实际观察月亮形状
  3. 绘制月相变化图
  4. 预测下个月的月相

## 推荐学习路径

1. **入门**（1-2 周）：使用 NASA Space Place 了解太阳系基本概念
2. **认星**（1 个月）：用 Stellarium 学习主要星座和亮星
3. **深入**（2-3 个月）：完成实践课题，参加 CNAO 预赛
4. **拓展**：阅读《天文爱好者》杂志，关注天文最新发现
