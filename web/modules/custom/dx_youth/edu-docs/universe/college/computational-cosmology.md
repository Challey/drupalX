## 第一章 数值宇宙学模拟

### 1.1 为什么需要计算机模拟

宇宙学研究的独特挑战：
- **无法做实验**：不能创造或操控宇宙
- **时间尺度巨大**：宇宙演化以十亿年为单位
- **唯一性**：我们只有一个可观测宇宙
- **非线性结构形成**：暗物质晕、星系形成涉及复杂物理

**计算机模拟的作用：**
- 从初始条件（CMB）出发，模拟宇宙演化
- 预测可观测量的统计分布
- 与真实观测数据对比，检验宇宙学模型

### 1.2 N 体模拟

**核心思想：** 将暗物质离散化为大量粒子，计算引力相互作用。

**关键算法：**

| 算法 | 复杂度 | 特点 |
|------|--------|------|
| 直接求和 | O(N²) | 精确但极慢 |
| 树算法（Barnes-Hut） | O(N log N) | 远距离粒子分组近似 |
| PM（粒子网格） | O(N log N) | 用 FFT 计算引力势 |
| P³M | O(N log N) | 短程直接 + 长程网格 |
| 快速多极子（FMM） | O(N) | 最优复杂度 |

### 1.3 主流宇宙学模拟项目

| 模拟 | 规模 | 盒子大小 | 特点 |
|------|------|---------|------|
| **Millennium** | 10¹⁰ 粒子 | 500 Mpc/h | 经典暗物质模拟 |
| **IllustrisTNG** | 多尺度 | 50-300 Mpc/h | 含重子物理 |
| **EAGLE** | 10¹⁰ 粒子 | 100 Mpc/h | 星系形成 |
| **Uchuu** | 2.1×10¹² 粒子 | 2 Gpc/h | 最大规模 |
| **AbacusSummit** | 多运行 | 多种 | DESI 分析用 |

### 1.4 实践：用 Python 做简易 N 体模拟

```python
import numpy as np

class NBodySimulation:
    def __init__(self, n_particles, box_size):
        self.n = n_particles
        self.box = box_size
        # 随机初始位置
        self.pos = np.random.rand(n_particles, 3) * box_size
        self.vel = np.zeros((n_particles, 3))
        self.mass = np.ones(n_particles) * (box_size**3 / n_particles)

    def compute_forces(self, softening=0.01):
        """计算引力（直接求和 + 软化）"""
        forces = np.zeros_like(self.pos)
        for i in range(self.n):
            for j in range(i+1, self.n):
                diff = self.pos[j] - self.pos[i]
                # 周期性边界
                diff = diff - self.box * np.round(diff / self.box)
                dist = np.linalg.norm(diff)
                force_mag = self.mass[i] * self.mass[j] / (dist**2 + softening**2)
                force_dir = diff / dist
                forces[i] += force_mag * force_dir
                forces[j] -= force_mag * force_dir
        return forces

    def step(self, dt):
        """Leapfrog 积分"""
        forces = self.compute_forces()
        acc = forces / self.mass[:, np.newaxis]
        self.vel += acc * dt
        self.pos += self.vel * dt
        # 周期性边界
        self.pos = self.pos % self.box

# 运行模拟
sim = NBodySimulation(n_particles=100, box_size=1.0)
for step in range(1000):
    sim.step(dt=0.001)
```

## 第二章 引力波天文学

### 2.1 引力波的发现

**2015 年 9 月 14 日**，LIGO 首次直接探测到引力波（GW150914）：
- 两个黑洞合并（36 + 29 → 62 太阳质量）
- 3 个太阳质量转化为引力波能量
- 信号传播了 13 亿年

**意义：** 开启了引力波天文学新纪元，2017 年诺贝尔物理学奖。

### 2.2 引力波探测器

| 探测器 | 位置 | 臂长 | 灵敏度频段 |
|--------|------|------|-----------|
| LIGO H1 | 美国汉福德 | 4 km | 10 Hz - 10 kHz |
| LIGO L1 | 美国利文斯顿 | 4 km | 10 Hz - 10 kHz |
| Virgo | 意大利比萨 | 3 km | 10 Hz - 10 kHz |
| KAGRA | 日本神冈 | 3 km | 地下、低温 |
| LISA（计划） | 太空 | 250 万 km | 0.1 mHz - 0.1 Hz |
| 太极/天琴（计划） | 太空 | 百万 km | 类似 LISA |

### 2.3 多信使天文学

**GW170817（2017 年 8 月 17 日）：** 首次引力波 + 电磁波联合观测
- 引力波信号：双中子星合并
- 1.7 秒后：费米卫星探测到伽马射线暴
- 数小时后：光学望远镜观测到千新星（kilonova）
- **证实**：重元素（金、铂）在中子星合并中产生

**多信使组合：**
```
引力波（LIGO/Virgo）→ 定位天区
    ↓
伽马射线（Fermi/INTEGRAL）→ 确认方向
    ↓
光学/红外（VLT/Hubble/JWST）→ 详细观测
    ↓
射电（VLA/ALMA）→ 余辉观测
    ↓
中微子（IceCube）→ 高能过程
```

## 第三章 JWST 与新一代观测

### 3.1 詹姆斯·韦伯太空望远镜（JWST）

**2021 年 12 月 25 日发射**，2022 年 7 月发布首批图像。

**关键参数：**
- 主镜直径：6.5 米（18 块镀金铍镜面）
- 观测波段：0.6 - 28.5 微米（红外）
- 轨道：日地 L2 拉格朗日点（150 万公里）
- 工作温度：~40K（被动 + 主动制冷）

### 3.2 JWST 重大发现

1. **最遥远星系**：JADES-GS-z14-0（红移 z=14.32，大爆炸后 2.9 亿年）
2. **系外行星大气**：首次探测到系外行星大气中的 CO₂、SO₂
3. **恒星形成**：以前看不到的尘埃云内部结构
4. **早期宇宙**：发现大爆炸后早期就有大量成熟星系，挑战现有模型

### 3.3 其他新一代设备

| 设备 | 类型 | 状态 | 科学目标 |
|------|------|------|---------|
| **ELT** | 39m 光学望远镜 | 建设中 | 系外行星、第一代星系 |
| **SKA** | 射电望远镜阵列 | 建设中 | 宇宙黎明、脉冲星 |
| **LISA** | 空间引力波 | 2030s | 超大质量黑洞合并 |
| **Roman** | 空间望远镜 | 2027 | 暗能量、系外行星 |
| **中国巡天（CSST）** | 空间望远镜 | 2026 | 类似哈勃，大视场 |

## 第四章 暗物质与暗能量前沿

### 4.1 暗物质候选者

| 候选者 | 质量范围 | 探测方式 | 状态 |
|--------|---------|---------|------|
| WIMP | GeV-TeV | 地下直接探测 | 未发现 |
| 轴子（Axion） | μeV-meV | 微波腔实验 | ADMX 探索中 |
| 惰性中微子 | keV | X 射线观测 | 未确认 |
| 原初黑洞 | 多种 | 引力波/微透镜 | 部分参数空间开放 |
| 模糊暗物质 | ~10⁻²² eV | 星系结构 | 理论探索 |

### 4.2 暗能量本质

**观测事实：** 宇宙加速膨胀（1998 年发现，2011 年诺贝尔奖）

**理论解释：**

| 模型 | 状态方程 w | 特点 |
|------|-----------|------|
| 宇宙学常数 Λ | w = -1 | 真空能量，最简单 |
| 精质（Quintessence） | w > -1（变化） | 动态标量场 |
| 幽灵能量（Phantom） | w < -1 | 大撕裂结局 |
| 修改引力（f(R)） | 有效 w 变化 | 不需要暗能量 |

### 4.3 哈勃常数危机

**问题：** 不同方法测得的哈勃常数 H₀ 不一致：

| 方法 | H₀ (km/s/Mpc) | 不确定度 |
|------|-----------------|---------|
| CMB（Planck） | 67.4 | ±0.5 |
| 超新星（SH0ES） | 73.0 | ±1.0 |
| 引力透镜（H0LiCOW） | 73.3 | ±1.8 |
| 引力波标准汽笛 | 70（大误差） | ±10 |

**5σ 差异** → 可能暗示新物理！

**可能解释：**
- 早期暗能量
- 中微子新物理
- 系统误差（尚未发现）
- 需要新的宇宙学模型

### 5.1 AI + 宇宙学
