# 天文仿真工具与实践平台

> 面向全年龄段，从入门到专业的天文仿真软件与数据平台汇总。

## 一、Stellarium — 开源桌面天文馆

**最推荐的天文入门工具**，适合所有年龄段。

### 基本信息
- **官网**：https://stellarium.org/zh_CN/
- **源码**：https://github.com/Stellarium/stellarium
- **平台**：Windows / macOS / Linux
- **许可**：GNU GPL v2
- **语言**：含中文界面

### 核心数据
| 项目 | 数量 |
|------|------|
| 默认恒星 | 60 万+ |
| 扩展恒星 | 2.2 亿+ |
| 深空天体 | 8 万+（默认）/ 100 万+（扩展） |
| 星座文化 | 40+ 种（含中国古代星官） |
| 历法系统 | 35+ 种 |

### 教学特色
- **中国古代星官体系**：完整支持三垣二十八宿等传统星官命名与连线
- **时间旅行**：可跳转到任意历史或未来时刻，观察天体位置变化
- **多投影模式**：支持鱼眼投影（天象馆）、球形投影（自制圆顶）
- **脚本系统**：支持脚本自动化演示
- **插件扩展**：人造卫星、目镜模拟、望远镜控制等

### 适用场景
- 中小学认星教学
- CNAO 竞赛天球坐标练习
- 天文馆投影演示
- 文化天文学研究

## 二、Celestia — 3D 宇宙漫游

### 基本信息
- **官网**：https://celestiaproject.space/
- **源码**：https://github.com/CelestiaProject/Celestia
- **平台**：Windows / macOS / Linux / Android / iOS
- **许可**：GNU GPL v2

### 核心功能
- **实时 3D 宇宙模拟**：从地球表面到宇宙深处的无缝缩放
- **太阳系精确模型**：行星、卫星、小行星、彗星的精确轨道
- **恒星数据库**：Hipparcos 星表 11.8 万颗恒星
- **扩展星表**：支持数百万恒星的附加数据库
- **纹理贴图**：高分辨率行星表面纹理
- **时间控制**：加速/减速/倒退时间

### 教学应用
- 直观理解宇宙尺度层次：地球 → 太阳系 → 银河系 → 本星系群 → 可观测宇宙
- 行星轨道运动的可视化
- 日食/月食的 3D 演示
- 星际旅行的虚拟体验

---

## 三、WorldWide Telescope (WWT) — 虚拟望远镜

### 基本信息
- **官网**：https://www.worldwidetelescope.org/
- **开发**：微软研究院（现由 AAS 维护）
- **平台**：Windows / Web 版
- **许可**：免费

### 核心功能
- **多波段天图**：可见光、X 射线、红外、射电等多波段全天图
- **海量数据**：整合 Hubble、Chandra、Spitzer 等空间望远镜数据
- **导览模式**：由天文学家制作的宇宙导览解说
- **教室模式**：专为教学设计的天象演示
- **数据可视化**：上传自己的观测数据进行叠加分析

### 教学应用
- 对比不同波段下的宇宙面貌
- 使用真实天文数据做研究性学习
- 虚拟参观著名天文台和天体

## 四、NASA 数据平台与工具

### NASA 开放数据门户
- **地址**：https://data.nasa.gov/
- **内容**：NASA 全任务开放数据，包括天文、行星、太阳物理等
- **格式**：CSV、JSON、FITS 等标准格式
- **应用**：适合大学生做真实数据分析项目

### STScI 数据档案
- **地址**：https://www.stsci.edu/
- **内容**：哈勃、JWST、Roman 望远镜的科学数据
- **工具**：MAST 数据检索系统
- **应用**：专业级天文数据获取与分析

### CAMELS 宇宙模拟数据集
- **地址**：https://camels.readthedocs.io/
- **内容**：最大规模的宇宙模拟数据套件，免费下载
- **规模**：数千个宇宙模拟，涵盖不同物理参数
- **应用**：AI 宇宙学训练、宇宙大尺度结构研究

## 五、Python 天文工具

### Astropy
- **官网**：https://www.astropy.org/
- **简介**：Python 天文学核心库，提供坐标转换、FITS 文件处理、时间系统等
- **安装**：`pip install astropy`
- **适用**：高中以上，有 Python 基础的学习者

### Astroquery
- **简介**：查询天文数据库的 Python 工具包
- **功能**：访问 VizieR、SIMBAD、NED 等天文数据库
- **安装**：`pip install astroquery`

### CosmicAI
- **地址**：https://cosmicai.org/code
- **简介**：将 AI 方法应用于天文数据的开源工具集
- **功能**：宇宙模拟分析、星系形态分类、引力透镜检测

## 六、实践项目建议

### 项目 1：用 Stellarium 制作天文日历
- **难度**：入门
- **内容**：制作当月可观测天体日历，标注行星位置、月相、流星雨等

### 项目 2：用 Celestia 录制宇宙漫游视频
- **难度**：入门
- **内容**：从地球出发，逐步放大到银河系、本星系群、可观测宇宙

### 项目 3：用 Astropy 分析变星数据
- **难度**：中级（需 Python 基础）
- **内容**：下载 AAVSO 变星观测数据，用 Python 绘制光变曲线

### 项目 4：用 NASA 数据研究系外行星
- **难度**：高级
- **内容**：从 NASA 系外行星数据库下载数据，分析行星半径与轨道周期关系

### 项目 5：用 CosmicAI 进行星系分类
- **难度**：高级
- **内容**：使用机器学习模型对星系图像进行形态分类
